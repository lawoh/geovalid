Guide d'utilisation de GeoValidator

GeoValidator est un outil de validation de données géographiques pour le Canada. Il détecte automatiquement vos colonnes en analysant les valeurs, pas les noms de colonnes. Vous pouvez nommer vos colonnes comme vous voulez !

Les 3 étapes simples

1

Importez votre fichier

Glissez-déposez ou sélectionnez votre fichier. De nombreux formats sont acceptés : CSV, XLS, XLSX, JSON, GeoJSON, KML, GPX...

2

Vérifiez l'aperçu

Consultez les 10 premières lignes et vérifiez que les colonnes latitude/longitude ont été correctement détectées.

3

Analysez & Exportez

Lancez l'analyse, visualisez sur la carte et exportez vos données validées dans le format de votre choix.

Structure des données

Obligatoire

Latitude

Valeur numérique entre -90 et 90. Pour le Canada : 41.67° à 83.11°

Détection auto par les valeurs, peu importe le nom de colonne

Obligatoire

Longitude

Valeur numérique entre -180 et 180. Pour le Canada : -141° à -52.62°

Détection auto par les valeurs, peu importe le nom de colonne

Optionnel

Code postal

Format canadien : A1A ou A1A1A1

Si présent, sera validé et inclus dans les stats

Optionnel

Province

Code 2 lettres : AB, BC, MB, NB, NL, NS, NT, NU, ON, PE, QC, SK, YT

Si présente, sera incluse dans les stats par province

Détection intelligente : L'application analyse les valeurs de chaque colonne pour déterminer automatiquement ce qu'elle contient. Vous n'avez pas besoin d'utiliser des noms de colonnes spécifiques comme "lat" ou "longitude".

Règles de validation

Données valides

  • Latitude entre 41.67° et 83.11°
  • Longitude entre -141° et -52.62°
  • Valeurs numériques correctes
  • Code postal au bon format (si fourni)
  • Lignes d'au moins 2 points
  • Polygones fermés, d'au moins 4 sommets, sans auto-intersection
  • Tous les sommets d'une ligne ou d'un polygone dans le Canada

Données invalides

  • Coordonnées hors du Canada
  • Valeurs non numériques
  • Latitude ou longitude manquante
  • Format code postal incorrect
  • Géométrie vide ou type non supporté
  • Polygone non fermé ou auto-intersecté

Pays pris en charge

Choix du pays

  • Pays disponibles : Canada, France (métropolitaine ou avec outre-mer), les 54 pays d'Afrique et le Somaliland
  • Zones contestées : triangle de Hala'ib rattaché à l'Égypte, Abyei et Kafia Kingi au Soudan, triangle d'Ilemi au Kenya ; Somaliland traité à part de la Somalie ; archipel des Chagos hors de Maurice (choix de Natural Earth)
  • Précision des contours : un point à moins d'environ 1 km d'une frontière terrestre peut être mal classé
  • Code postal vérifié seulement quand le pays a un format officiel confirmé
  • Maroc : contour selon le point de vue du Maroc (Sahara occidental, Ceuta et Melilla inclus)
  • France avec outre-mer : Guadeloupe, Martinique, Guyane, La Réunion et Mayotte
  • Le pays est suggéré d'après les coordonnées du fichier
  • Vous pouvez le changer avant de lancer l'analyse

Contrôle des coordonnées

  • Chaque point est comparé au contour réel du pays (Natural Earth)
  • Tolérance de 3 km le long des côtes, aucune le long des frontières terrestres
  • Régions reconnues par leur code, leur numéro ou leur nom

Géométries et projections

Types de géométrie

  • Points, lignes et polygones (avec trous)
  • MultiPoint, MultiLineString, MultiPolygon
  • GeoJSON, GeoPackage, Shapefile, KML/KMZ, GML, GPX, TopoJSON, WKT
  • CSV ou Excel avec une colonne WKT

Systèmes de projection

  • Projection lue dans le fichier : .prj (Shapefile), GeoPackage, GeoJSON, GML
  • Sans indication : WGS 84 si les coordonnées sont en degrés
  • Reprojection automatique en WGS 84 pour la validation et les exports
  • Lambert Québec, Canada Atlas Lambert, UTM, MTM, Web Mercator, Lambert-93, CC42 à CC50, Lambert II étendu, Merchich (Maroc)…

Questions fréquentes

Mes colonnes ne sont pas détectées automatiquement

Vérifiez que vos données de latitude sont entre -90 et 90, et vos longitudes entre -180 et 180. Pour de meilleurs résultats avec des données canadiennes, les latitudes devraient être entre 40 et 85, et les longitudes entre -145 et -50.

Formats de coordonnées supportés :

  • Degrés décimaux (DD) : 45.5019, -73.5674
  • DMS avec symboles : 45°30'15"N, 73°34'02"W
  • DMS avec espaces : 45 30 15 N, 73 34 02 W
  • DMS avec tirets : 45-30-15-N
  • DMS avec lettres : 45d30m15sN
Puis-je utiliser des données hors du Canada ?

Actuellement, l'application valide uniquement les coordonnées situées dans les limites géographiques du Canada. Les points hors de ces limites seront marqués comme invalides.

Comment fonctionne l'export Shapefile ?

L'export Shapefile génère un fichier ZIP contenant les 4 fichiers nécessaires : .shp (géométries), .shx (index), .dbf (attributs) et .prj (projection WGS84).

Mes données sont-elles sécurisées ?

Oui ! Toutes les opérations sont effectuées localement dans votre navigateur. Aucune donnée n'est envoyée vers un serveur externe.
